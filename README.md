# Trường THCS-THPT Đốc Binh Kiều

Web application demo cho quản lý học tập và nhân sự của trường THCS-THPT Đốc Binh Kiều.

## Công nghệ

- React + Vite + TypeScript
- CSS tùy chỉnh
- Dự án đang được phát triển theo mô hình từng phần

## Chạy local

```bash
npm install
npm run dev -- --host
```

## Build production

```bash
npm run build
```

## Mục tiêu phát triển

- Dashboard quản trị trường học
- Quản lý nhân sự
- Báo cáo & tài liệu
- Import / Export dữ liệu
- Xác thực người dùng và phân quyền sau này

## Deploy

Dự án sẵn sàng tích hợp với Vercel sau khi đã push lên GitHub.
